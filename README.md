# Estudos em C 📚

Este repositório contém meus estudos sobre a linguagem **C**, incluindo conceitos fundamentais, estruturas de dados e técnicas avançadas como alocação dinâmica e ponteiros. Aqui você encontrará exemplos práticos e anotações que foram essenciais para o meu aprendizado.

## Estrutura do Repositório 🗂️

- **Conceitos Básicos** – Fundamentos da linguagem C.
- **Controle de Fluxo** – Estruturas condicionais (`if`, `else`, `switch-case`) e de repetição (`for`, `while`, `do-while`).
- **Funções** – Implementação e uso de funções.
- **Vetores e Matrizes** – Manipulação de arrays unidimensionais e multidimensionais.
- **Ponteiros** – Uso de ponteiros e aritmética de ponteiros.
- **Alocação Dinâmica** – Uso de `malloc`, `calloc`, `realloc` e `free`.
- **TADs (Tipos Abstratos de Dados)** – Implementação de TADs.
- **Listas** – Listas encadeadas e operações básicas.
- **Pilhas** – Implementação de pilhas e operações (`push`, `pop`).
- **Filas** – Implementação de filas e operações (`enqueue`, `dequeue`).

## Tecnologias Utilizadas 🛠️

- **Linguagem C**
  - Compilador: GCC (GNU Compiler Collection)
  - IDEs: VS Code, Code::Blocks
  - Controle de versão: Git & GitHub
